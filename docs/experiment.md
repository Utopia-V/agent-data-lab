# 实验协议

## 研究问题

在强模型拥有普通文件工具与编程能力时，附加的数据访问约定是否仍有独立收益？区分三种收益来源：数据说明、可复用的确定性处理、跨来源统一约定。

## 比较条件

| 条件 | 模型可见能力 | 用途 |
| --- | --- | --- |
| files | 原始语料、正常目录与格式说明、shell/Python | 普通文件工作基线 |
| described | files 加来源语义、字段含义与关联说明 | 测量数据说明的贡献 |
| interface | described 加可组合的范围、读取、引用查询接口 | 测量接口相对说明的增量 |

所有条件允许一次代码执行批量读取、循环和筛选。底层事实相同；不为 interface 条件预先提供其他条件无法获得的语义答案。

## 任务与评分

任务覆盖已知对象直接读取、穷尽枚举、跨来源连接、显式引用位置、限定范围后检索、未覆盖范围与损坏来源、重定位后的身份和版本变化。题目按实际需要选取这些行为，不强制每道题经历全部接口。

标准答案从生成器创建时的事实与独立检查得到。结果比较保留漏项、误报、定位错误、错误完整性声明和最终结果，不用总分掩盖具体失败。

首轮为探索实验。任务、语料 seed、条件、模型与思考强度配对固定，运行顺序随机化。根据轨迹改进接口后使用新实验版本；旧结果不被覆盖，也不把用于修改的样例称为独立验证。

## 测量

- 任务结果与覆盖声明的正确性。
- 实際发生的工具调用、模型调用（只有运行入口能可靠观测时记录）、耗时与报告的 token 使用。
- 工具交付字节数、截断与失败重试；这些指标独立报告，不换算成 token 或模型延迟。
- 实现和维护代价：额外源说明、适配代码、建立与刷新派生结构所需工作。

## 健壮性

确定性测试覆盖重复引用、代码块伪链接、空范围、重复范围成员、移动对象、过期版本、缺失与损坏来源、未支持的格式、查询范围遗漏、输出截断和未知对象。使用多个 seed 和变形测试，检查结果随移动、重排及加入无关数据的变化。

真实模型实验另外保留失败轨迹，判断错误发生在发现、参数、查询覆盖、结果解释还是最终回答。

## 收束条件

完整保留产生结论的实现版本、实验参数与可重建材料。确定性行为成立后，依据配对模型实验决定保留、修改或撤回候选接口。收益不足时收窄到说明约定或源端辅助函数；不以已投入代码量决定保留。

# Agent 数据访问实验

本项目研究 Agent 在文件、结构化记录与派生索引之间取得数据的方式。实验比较普通文件工具、附带数据说明的文件工具，以及增加统一寻址、范围查询和引用查询的访问方式。

问题是：在允许模型自行编程、筛选和组合结果的前提下，哪些额外约定仍能改善任务结果、减少模型往返或降低错误恢复成本？

这是独立实验项目。候选接口不属于 Repa 已接受的产品协议。
